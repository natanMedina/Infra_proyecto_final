# Portfolio Analytics Pro 🚀

## Plataforma de Análisis Financiero Avanzado

**Portfolio Analytics Pro** es una aplicación web moderna y profesional diseñada para el análisis de mercados financieros mediante técnicas avanzadas de computación distribuida y análisis de sentimiento.

## 🎨 Características del Diseño

### **Tema Visual Único**

- **Paleta de colores**: Gradientes emerald-teal, purple-pink, orange-red
- **Diseño moderno**: Cards con bordes redondeados y sombras elegantes
- **Modo oscuro/claro**: Transiciones suaves entre temas
- **Iconografía**: Lucide React para iconos consistentes
- **Tipografía**: Jerarquía visual clara y legible

### **Experiencia de Usuario**

- **Navegación intuitiva**: Pestañas con iconos descriptivos
- **Feedback visual**: Notificaciones y alertas personalizadas
- **Responsive design**: Optimizado para todos los dispositivos
- **Animaciones**: Transiciones suaves y efectos hover

## 📊 Módulos Principales

### **1. Análisis de Mercado Social** 📈

- **Gradiente**: Emerald a Teal
- **Funcionalidades**:
  - Análisis de sentimiento de redes sociales
  - Filtrado por criterios de engagement
  - Visualización de retornos acumulados
  - Configuración dinámica de estrategias

### **2. Trading de Alta Frecuencia** ⚡

- **Gradiente**: Purple a Pink
- **Funcionalidades**:
  - Estrategias intradía con análisis técnico
  - Modelos GARCH para predicción de volatilidad
  - Indicadores RSI y Bandas de Bollinger
  - Descarga de datos en CSV

### **3. Análisis de Rendimiento** 📊

- **Gradiente**: Orange a Red
- **Funcionalidades**:
  - Comparación secuencial vs paralelo
  - Métricas de tiempo y CPU
  - Gráficos de rendimiento
  - Análisis de eficiencia

## 🛠️ Tecnologías Utilizadas

### **Frontend**

- **React 19** - Framework principal
- **Vite** - Build tool y dev server
- **Tailwind CSS 4** - Framework de estilos
- **Recharts** - Gráficos interactivos
- **Lucide React** - Iconografía
- **React Hot Toast** - Notificaciones
- **SweetAlert2** - Alertas avanzadas

### **Backend Integration**

- **FastAPI** - API REST
- **Ray** - Computación distribuida
- **Proxy configurado** - Desarrollo sin CORS

## 🚀 Instalación y Uso

### **Desarrollo Local**

```bash
cd Client
npm install
npm run dev
```

### **Producción**

```bash
npm run build
```

### **Docker**

```bash
docker-compose up
```

## 🔧 Configuración Avanzada

### **Variables de Entorno**

```env
VITE_API_URL=http://localhost:8000
VITE_APP_TITLE=Portfolio Analytics Pro
```

### **Personalización de Temas**

Los colores y gradientes se pueden personalizar en:

- `src/App.jsx` - Header y navegación
- `src/pages/*.jsx` - Headers de cada módulo
- `tailwind.config.js` - Configuración de colores
